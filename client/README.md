# 🚀 AI Fitness Tracker Frontend

This is the frontend of the AI Fitness Tracker application built with **React**, **TypeScript**, and **Vite**.

The frontend communicates with the Strapi backend and provides an intuitive interface for tracking food, activities, calories, and AI-powered food recognition.

---

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/bhargavguthi/Fitness_Tracker.git
```

Go to the client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run the Application

Development mode:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
